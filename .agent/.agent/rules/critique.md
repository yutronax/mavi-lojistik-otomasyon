# Self-Critique and Verification Rules

## Mandatory Internal Critique
- **The "Wait, What?" Check**: Before finalising any implementation plan, the agent must ask: "Is this really the best way? What am I missing?"
- **Critique Section**: Every `implementation_plan.md` MUST include a "Critique & Self-Debate" section.
- **Verification Questioning**: Explicitly ask: "Is there a specific part of this that I should test with a script before writing the full code?"

## Questioning Progress
- If a task seems to be stuck or repeating, the agent must stop and perform a "Lvl 2 Debate" to find a different path.
- Always check if the user's intent is being fully met or if I'm just completing the sub-tasks mechanically.
