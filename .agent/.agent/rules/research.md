# Research and Documentation Standards

## Source Integrity
- **Quality Over Quantity**: Prioritize official documentation, academic papers, and established technical blogs (e.g., Medium, Dev.to, GitHub repos).
- **Multi-Source Verification**: Do not rely on a single source for critical facts. cross-reference at least 3 sources.
- **International Scope**: If the topic is global (e.g., software frameworks), search in English for the most up-to-date data, but synthesize the results in Turkish as per user preference.

## Documentation Structure
- Every research task must result in a structured `research_report.md`.
- **Mandatory Sections**:
    - **Executive Summary**: 1-paragraph overview.
    - **Key Findings**: Bullet points of critical data.
    - **Detailed Analysis**: In-depth exploration of the topic.
    - **Sources & Citations**: List of all URLs consulted.
