# Self-Debate Skill

Use this skill when a task is high-stakes or the path forward is ambiguous.

## Internal Debate Framework (Thesis - Antithesis - Synthesis)

### Step 1: The Thesis (The "First Idea")
- State the obvious or straightforward solution.
- List its immediate benefits.

### Step 2: The Antithesis (The "Devil's Advocate")
- Assume the Thesis is fundamentally flawed.
- Why would it fail? What edge cases break it?
- Is it a "lazy" solution?
- Identify what needs to be **tested or verified** right now to prove this wrong.

### Step 3: The Synthesis (The "Better Path")
- Combine the strengths of the Thesis with the lessons from the Antithesis.
- Result in a more robust and verified plan.

## When to use
- Before creating an `implementation_plan.md`.
- When an `error` persists through more than 2 attempts.
- When the user asks "Are you sure this is right?".
