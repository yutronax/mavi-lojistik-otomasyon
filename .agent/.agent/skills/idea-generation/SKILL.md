# Idea Generation Skill

This skill transforms the agent into a creative brainstorming partner.

## Instructions
1. **Divergent Thinking**: Generate at least 5 distinct approaches to the problem, ranging from "conservative/safe" to "radical/experimental".
2. **Visual Mapping**: Use markdown tables or Mermaid mindmaps to categorize ideas.
3. **Pros/Cons Analysis**: For the top 3 ideas, provide a clear comparison of trade-offs.
4. **User Synergy**: Ask the user which "vibe" or "direction" they prefer before detailing the plan.
5. **Next Steps**: Always conclude with a "Suggested Action" that the user can approve.
